# FTP Deployer — 배포본

로컬 폴더의 파일을 **여러 FTP/FTPS 서버에 안전하게 올려주는 macOS 데스크탑 앱**의 설치 파일을 받는 곳입니다.
소스 코드는 여기에 없습니다. **[Releases](../../releases)** 에서 최신 `.dmg`를 받으세요.

> 인텔 맥과 애플 실리콘(M1~) 맥 모두에서 동작하는 **유니버설 빌드**입니다.

## 설치하기

앱이 **코드 서명되어 있지 않아** macOS가 첫 실행을 막습니다. 아래 순서를 **한 번만** 거치면 이후에는 더블클릭으로 열립니다.

1. [Releases](../../releases)에서 `.dmg`를 받아 열고, 앱을 **`응용 프로그램(Applications)`** 폴더로 드래그합니다.
2. 응용 프로그램에서 앱을 **더블클릭** → **"열 수 없습니다"** 경고가 뜨면 **`닫기`** 를 누릅니다.
   *(여기서 한 번 실행을 시도해야 다음 단계의 버튼이 나타납니다.)*
3. **`시스템 설정` → `개인정보 보호 및 보안`** 을 열고 아래로 내리면 차단 안내와 함께 **`확인 없이 열기`** 버튼이 있습니다. 누르고 암호를 입력하면 실행됩니다.

**macOS 14(Sonoma) 이하**라면 더 간단합니다 — 앱을 **우클릭 → `열기`** → 경고창에서 다시 **`열기`**.

### "손상되어 열 수 없습니다"라고 뜬다면

다운로드 격리 표시 때문입니다. 터미널에 아래를 한 번 실행하세요.

```bash
xattr -dr com.apple.quarantine /Applications/ftp-deployer.app
```

## 업데이트

앱은 **자동으로 업데이트되지 않습니다.** 새 버전이 나오면 앱 상단에 안내 배너가 뜨니, 여기서 새 `.dmg`를 받아 **같은 방법으로 덮어써 설치**하면 됩니다. 등록해둔 서버 목록과 설정은 그대로 유지됩니다.

## 사용법

앱 안에서 **설정(⚙️) → 매뉴얼 보기** 로 짧은 사용 가이드를, **상세 매뉴얼 다운로드(.md)** 로 전체 문서를 볼 수 있습니다.

## 문의
